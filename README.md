## 游戏内容

- 17 种现代单位，包括 J-20 玩家战机、首领战机、普通敌机及地面目标。
- 六关、六套现代背景，原始高清 PNG 素材与清晰字体保留。
- 四种武器，当前最高三级；普通模式、街机模式及已解锁关卡练习。
- 中文菜单、设置、战斗提示和结算；精细移动、判定点及画面效果设置。
- 弹幕复用、运动路径碰撞、分批后台加载、背景缓存等性能优化。
- 修复“强敌来袭”提示到期后不消失的问题。

## 维护源码

发布页提供 `modern-striker-1.0.0-source.zip`，保留完整目录结构，包含可编辑的覆盖脚本、高清素材、资源元数据、重建脚本与验证摘要。它是现有游戏的维护覆盖层，场景和原资源底包仍随发布 EXE 内嵌；不是独立的 Godot 编辑器工程。

解压源码归档，并将发布 EXE 保存到另一个目录。使用 Python 3.10 或以上版本即可重建，不依赖原工作区、Godot 安装或第三方 Python 包：

```powershell
python rebuild.py --base "C:/Games/现代突击者_正式版.exe" --output "./现代突击者_正式版.exe"
```

修改 `source/` 中的脚本或素材后重复上述命令。未修改源码的重建结果与 1.0.0 发布 EXE 的 SHA256 完全一致。

若需复跑开发检查，在重建目录运行 `python run_verification.py`。该脚本运行所列 26 个用例；发布时的 34 组完整记录包含另外的关卡与压力验证，见校验摘要。开发检查不会通过普通游戏启动自动启用。
